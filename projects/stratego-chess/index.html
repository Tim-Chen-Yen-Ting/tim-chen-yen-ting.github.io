♟️ Stratego-Chess♟️ 行軍西洋棋 Stratego-Chess

What if chess no longer has a 100% capture rate?

如果西洋棋的吃子不再是 100% 成功呢？

1The problem問題

Chess is perfect information: everything is on the board. Stratego is all hidden information, but its pieces just shuffle forward one square at a time. What happens if you put the secrets onto chess movement?

西洋棋是完全資訊：一切都在棋盤上。行軍棋全是隱藏資訊，但它的棋子只會一格一格往前挪。如果把那些祕密放到西洋棋的走法上，會發生什麼事？

2My solution我的解法

Welcome to the child of Chess and Stratego. Every piece moves like a chess piece (public), but also carries a hidden rank (secret) that decides what it beats. You can see how an enemy piece moves, never what it can capture. It is not chess: there's no checkmate, the king is just a piece, and passing is always legal. If you came to castle your way to safety, welcome.

歡迎來到西洋棋和行軍棋的孩子。每顆棋子都像西洋棋那樣移動（公開），同時帶著一個暗藏的階級（祕密），決定它打得贏誰。你看得到敵方棋子怎麼走，卻永遠不知道它能吃掉什麼。這不是西洋棋：沒有將死、國王只是一顆普通的棋子、而且隨時可以跳過。如果你是來靠易位保平安的，歡迎。

No friends? No worries. There's a bot to play against, and the game is LLM friendly: swap /g/ with /llm/ in the URL and a chatbot can play by fetching plain links.

沒朋友？沒關係。有機器人可以陪你下，而且這個遊戲對 LLM 很友善：把網址裡的 /g/ 換成 /llm/，聊天機器人就能靠抓取純連結來下棋。

3Challenges & fun stories挑戰與趣事

The fun problem is that information leaks everywhere. If the game announced "equal rank" and "bomb" differently, the announcement itself would reveal a hidden piece, so both read as the same mutual destruction. Engineers and the flag are both immune to bombs, because an immunity only one piece had would point right at it. If your setup timer runs out, the server deals you a random legal army, since a predictable default is a leaked army.

有趣的問題在於資訊會從各處洩漏。如果遊戲對「同階」和「爆裂物」的公告不一樣，公告本身就會洩漏暗棋，所以兩者都顯示成同樣的同歸於盡。工兵和軍旗都對爆裂物免疫，因為如果只有一種棋子免疫，就等於直接指名它。如果你的佈署計時用完，伺服器會替你發一支隨機的合法軍隊，因為可預測的預設值就是洩漏的軍隊。

The bot is a particle filter that keeps a running probability for what each of your pieces might be, and it plays a little randomly on purpose: a deterministic bot leaks its own ranks over enough games just by which move it reliably picks.

機器人是個粒子濾波器，持續維護你每顆棋子可能是什麼的機率，而且刻意帶點隨機：確定性的機器人只要下得夠多局，光靠它固定會選哪一步，就會洩漏自己的階級。

4Tech stack & what I learned技術堆疊與我學到的

TypeScriptFastify 5Socket.IOReact 19ViteZustandVitest

My first step into TypeScript, and my first time seeing client/server lessons up close. As a non-CS student I learned those lessons the hard way, and thank god Claude Code exists. The biggest takeaway was to make a leak structurally impossible: hidden ranks leave the server through exactly one function, so there's no display filter to forget about.

我踏進 TypeScript 的第一步，也是第一次近距離接觸前後端的課題。身為非資工系的學生，這些課我都學得很辛苦，感謝老天有 Claude Code。最大的收穫是讓洩漏在結構上不可能發生：暗棋的階級只會通過唯一一個函式離開伺服器，所以不存在會被忘記的顯示過濾器。
