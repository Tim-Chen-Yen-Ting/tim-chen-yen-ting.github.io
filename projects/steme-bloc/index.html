🧠 STEME & BLOC

What if you could turn "sincerity" into a number without calling an LLM every time?

如果不用每次呼叫 LLM，就能把「真誠」變成數字呢？

1The problem問題

Civilizism constantly has to translate between words and numbers: how sincere is this person, do these two memories express the same belief, are these two beliefs fighting each other? Doing that with an LLM call every time would be slow, expensive and inconsistent.

Civilizism 不斷需要在文字和數字之間轉換：這個人有多真誠？這兩段記憶表達的是同一個信念嗎？這兩個信念彼此衝突嗎？每次都用 LLM 呼叫來做，會又慢、又貴、又不一致。

2My solution我的解法

STEME (Semantic Transformation & Evaluation Mapping Engine) is the translation layer. It combines calibrated embedding similarity, zero-shot entailment classification, and an emotion classifier, and it can anchor abstract concepts like sincerity using definitions plus polar behavioral examples. BLOC (Belief & Label-Oriented Clustering) groups memories into beliefs that drift as new experiences arrive, and flags opposing beliefs as internal conflict.

STEME（語意轉換與評估對應引擎）是翻譯層。它結合校準過的嵌入相似度、零樣本蘊含分類，以及情緒分類器，還能用定義加上兩極的行為範例，替真誠這類抽象概念定錨。BLOC（信念與標籤導向分群）把記憶分成會隨新經驗漂移的信念，並把彼此對立的信念標記為內在衝突。

3Challenges & fun stories挑戰與趣事

Raw cosine similarity is a trap: embedding scores crowd into a narrow band, so I had to recalibrate them to get any separation. And clustering by cosine similarity makes centroids crowd together as meaning drifts, so BLOC uses entailment to decide cluster membership instead.

原始的餘弦相似度是個陷阱：嵌入分數會擠在很窄的區間內，所以我得重新校準才能拉開差距。而且用餘弦相似度分群，會讓質心隨語意漂移而擠在一起，所以 BLOC 改用蘊含關係來決定群的歸屬。

I thought STEME (essentially 1-NN) was a universal tool, until the emotion projection pushed everything toward the center, and I realized I needed a different classification method. The chart shows real benchmark output: STEME scores 0.79–0.91 F1 across four embedding models on a synthetic tagging set, and BLOC gets 0.70 ARI on drifting data versus 0.57 for global k-means.

我本來以為 STEME（本質上就是 1-NN）是萬用工具，直到情緒投影把所有東西都推向中心，我才意識到需要另一種分類方法。圖中是真實的基準測試輸出：在一組合成的標註資料上，STEME 於四種嵌入模型的 F1 為 0.79–0.91；在漂移資料上，BLOC 的 ARI 是 0.70，全域 k-means 則是 0.57。
